📚 英文學習系統 - 功能列表
核心功能
✅ 讀取 JSON 數據 - 從 output.json 載入所有單詞
✅ 單詞統計 - 顯示共有多少項單詞
✅ 全部展開顯示 - 所有單詞行默認展開，無需分頁

單詞資訊顯示
✅ Tag 標籤 - 顯示單詞所屬單元 (U1, U2...)
✅ 單字 - 英文單詞
✅ 音標 - 國際音標
✅ 詞性 - 名詞(n.)、動詞(v.)等
✅ 中文解釋 - 單詞的中文意思
✅ 例句 - 英文例句
✅ 翻譯 - 例句的中文翻譯

互動功能
✅ 點擊發音 - 點擊單字時播放英文發音（Web Speech API）

視覺設計
✅ 淡藍色系配色 - 奇偶列用不同淡藍背景
✅ 垂直置中 - 所有內容垂直對齐
✅ Hover 效果 - 滑鼠懸停時顯示視覺反饋
✅ 響應式設計 - 支援不同屏幕尺寸

排序
✅ 原始順序 - 按照 JSON 文件的原始順序排列



加入 PWA
1.快取優先
2.整頁快取
更新策略
1. index.html [設定] 下有[更新]鈕，按下後檢查更新，有新版本就更新
2. 瀏覽器定時自動檢查，有新版時，在[設定]及[更新]鈕左上角出現紅點
3. 可UI 停用/刪除/啟用 service worker
